# Guide photo credits

Reference photos for the disease guides. The same files are in the website at `public/guides/`.
Every photo is CC0, CC BY or CC BY-SA. Photos were resized (max 1000 px wide), lightly cropped where a dataset image had black rotation corners, and saved as JPEG without metadata.

Roboflow images come from the PinyaSuri AI dataset (`ece-4-workspace/pinyasuri-ai-2`, Philippines, CC BY 4.0), the dataset the scan model was trained on. These images are 512 px, so they are smaller than the other photos.
