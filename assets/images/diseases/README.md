# Disease photos for the Guide tab

Put one photo per disease here, with exactly these names:

| File | Disease |
|---|---|
| healthy.jpg | No Disease Detected |
| crown_rot.jpg | Crown Rot |
| fruit_rot.jpg | Fruit Rot |
| fruit_fasciation.jpg | Fruit Fasciation |
| mealybug_wilt.jpg | Mealybug Wilt of Pineapple |
| multiple_crown.jpg | Multiple Crown |

The path for each disease is the `image` field in
`assets/data/remediation_protocols.json`. A missing file shows a placeholder.
Keep each photo around 1000 px wide so the app stays small.
