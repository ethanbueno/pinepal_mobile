# Disease photos for the Guide tab

Put up to five photos per condition here, with exactly these names. The first
one is the main photo (also used as the list thumbnail); the other four show
next to it in the guide header.

| Condition | Files |
|---|---|

| Crown Rot | crown_rot.jpg, crown_rot_2.jpg, crown_rot_3.jpg, crown_rot_4.jpg, crown_rot_5.jpg |

| Multiple Crown | multiple_crown.jpg, multiple_crown_2.jpg, multiple_crown_3.jpg, multiple_crown_4.jpg, multiple_crown_5.jpg |

The paths for each condition are the `images` list in
`assets/data/remediation_protocols.json` (`image` is the first one). A missing
file shows a "Photo coming soon" placeholder.

Keep each photo around 1000 px wide so the app stays small. Copy the same files,
with the same names, to the website's `public/guides/` folder.
